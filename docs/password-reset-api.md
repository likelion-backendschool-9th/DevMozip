# 비밀번호 재설정·변경 API

비밀번호를 모를 때 메일 링크로 재설정하는 흐름(`/forgot-password`)과 로그인한 회원이 비밀번호를 바꾸는 흐름(`/settings/privacy`)의 계약이다. 환경변수는 [환경 준비 안내](setup-after-ai.md), 운영 설정은 [운영 안내](deployment-operations.md)를 참조한다. 비밀번호 없는 카카오 회원의 첫 비밀번호 설정은 [카카오 인증 API](kakao-auth-api.md)도 함께 본다.

## BFF

브라우저는 서버 액션만 호출한다. 정의는 [lib/auth/actions.ts](../frontend/lib/auth/actions.ts)에 있다.

| 서버 액션 | 내용 |
|---|---|
| `requestPasswordResetAction(email)` | 이메일을 정규화하고 들어온 `x-real-ip`를 `X-Real-IP`로 넘긴다. |
| `resetPasswordAction(input)` | 성공하면 로그인 쿠키를 지운다. 401이면 `{error, expired: true}`를 돌려준다. |
| `changePasswordAction(input)` | 비밀번호가 있는 회원의 변경. 성공하면 로그인 쿠키를 지운다. |
| `setPasswordAction(input)` | 비밀번호 없는 카카오 회원의 첫 설정. 로그인을 유지한다. |

| 화면 | 동작 |
|---|---|
| `/forgot-password` | 주소에 `#token=`이 없으면 요청 폼, 있으면 새 비밀번호 폼을 보여 준다. 토큰은 읽은 즉시 주소에서 지운다. |
| `/login?password=reset`, `/login?password=changed` | 결과 안내를 표시한다. URL에는 코드만 싣고 문구는 화면이 정한다. |
| `/settings/privacy` | 서버의 회원 상태에 따라 변경 폼 또는 첫 설정 폼을 보여 준다. |

## 백엔드 API

| 메서드·경로 | 인증 | 요청 | 성공 응답 |
|---|---|---|---|
| `POST /api/v1/auth/password/reset-request` | 없음 | `{email}`, 선택 헤더 `X-Real-IP` | 202 본문 없음 |
| `POST /api/v1/auth/password/reset` | 없음 | `{token, newPassword, confirmPassword}` | 204 |
| `PATCH /api/v1/users/me/password` | 필요 | `{currentPassword?, newPassword, confirmPassword}` | 204 |

대상 회원은 재설정에서는 토큰, 변경에서는 인증 정보로 정한다. 요청 값으로 회원을 지정할 수 없다. 비밀번호 규칙은 가입과 같다(영문·숫자 포함 8~64자, BCrypt 72바이트 이내).

### 재설정 요청

회원을 조회하기 전에 202로 응답한다. 회원 조회, 토큰 저장, 메일 발송은 전용 스레드에서 처리하므로 응답 내용과 시간으로 가입 여부가 드러나지 않는다. 처리 중 실패는 응답에 반영되지 않고 로그에 예외 클래스 이름만 남는다.

| 회원 상태 | 처리 |
|---|---|
| 비밀번호 있음, 정지 아님(`ACTIVE`, `WARNED`) | 토큰 발급, 재설정 메일 |
| 비밀번호 없음, 카카오 있음, 정지 아님 | 토큰 없는 안내 메일 |
| 정지, 미가입 | 보내지 않음 |
| 같은 이메일의 제한 초과 | 보내지 않음 |

재설정 메일의 링크는 `{DOMAINNAME}/forgot-password#token=...`이고, 카카오 안내 메일의 링크는 `{DOMAINNAME}/login?next=/settings/privacy`다. 요청의 Host 헤더로 주소를 만들지 않는다.

### 재설정

입력 규칙을 먼저 검사하고 통과한 뒤에 토큰을 소비한다. 입력 실수로는 링크가 소진되지 않는다. 성공하면 리프레시 토큰을 지워 모든 기기에서 로그아웃된다.

### 변경

요청 값이 아니라 저장된 회원 상태로 분기한다.

| 회원 상태 | `currentPassword` | 처리 |
|---|---|---|
| 비밀번호 있음 | 필수, 일치해야 함 | 변경, 리프레시 토큰과 재설정 토큰 삭제 |
| 비밀번호 없음, 카카오 있음 | 보지 않음 | 첫 비밀번호 저장, 로그인 유지 |
| 비밀번호 없음, 카카오 없음 | 보지 않음 | 409 |

### 실패 응답

오류는 기존 `ErrorResponse` 형식이다.

| 경로 | 상태 | 상황 |
|---|---|---|
| `reset-request` | 400 | 이메일 형식 오류 |
| | 429 | 같은 IP의 요청 제한 초과 |
| | 503 | 메일 설정 없음, 발송 대기열 가득 참 |
| `reset` | 400 | 비밀번호 규칙 위반, 확인 불일치. 토큰을 소비하지 않는다. |
| | 401 | 토큰 없음·위조·만료·사용됨, 정지 회원. 문구는 모두 같다. |
| `PATCH` | 400 | 비밀번호 규칙 위반, 확인 불일치, 현재 비밀번호 누락·불일치, 현재와 같은 새 비밀번호 |
| | 401 | 로그인 필요 |
| | 403 | 정지 회원 |
| | 409 | 비밀번호도 카카오 연동도 없는 계정 |

현재 비밀번호 불일치를 401로 응답하지 않는 것은 BFF와 화면이 401을 로그인 만료로 처리하기 때문이다.

## 토큰과 제한

토큰은 `SecureRandom` 32바이트를 base64url로 인코딩한 값이다. 저장소에는 SHA-256 해시만 두며, `GETDEL`로 소비해 동시 요청 중 하나만 통과한다. 회원당 마지막 토큰 하나만 유효하다.

| 항목 | 값 | 설정 |
|---|---|---|
| 링크 수명 | 30분 | `password-reset.token-ttl` |
| 같은 이메일의 재요청 간격 | 60초 | `password-reset.email-cooldown` |
| 같은 이메일의 시간당 요청 | 5회. 초과해도 202로 응답하고 보내지 않는다. | `password-reset.email-hourly-limit` |
| 같은 IP의 시간당 요청 | 20회. 초과하면 429다. 헤더가 없으면 이 제한만 건너뛴다. | `password-reset.ip-hourly-limit` |

시간당 횟수는 첫 요청부터 잰다. 거절된 요청은 세지 않고 구간을 늘리지도 않는다.

| Redis 키 | 값 | 수명 |
|---|---|---|
| `password-reset:token:{토큰 해시}` | 이메일 | 30분 |
| `password-reset:member:{이메일}` | 토큰 해시 | 30분 |
| `password-reset:cooldown:{이메일}` | 1 | 60초 |
| `password-reset:count:email:{이메일}` | 횟수 | 1시간 |
| `password-reset:count:ip:{IP}` | 횟수 | 1시간 |

`local` 프로필은 같은 규칙의 메모리 구현을 쓴다.

## 메일 설정이 없을 때

서버는 정상 기동하고 `/actuator/health`도 메일 상태에 영향받지 않는다.

| 환경 | 메일 값이 모두 있음 | 메일 값이 없음 |
|---|---|---|
| `local` 프로필 | 실제 발송 | `MAIL_HOST`가 없으면 링크를 콘솔에 출력 |
| 그 외 | 실제 발송 | 재설정 요청만 503 |

## 제한

- 가입 이메일을 인증하지 않으므로 메일을 받는 사람이 곧 비밀번호를 바꿀 수 있는 사람이다. 가입 때 오타를 낸 주소의 주인은 그 계정을 가져갈 수 있다.
- `GET /api/v1/auth/check-email`이 가입 여부를 알려 주므로 가입 여부 노출이 완전히 막히지는 않는다.
- 이미 발급된 액세스 토큰은 비밀번호를 바꿔도 최대 30분 유효하다.
- 로그인과 현재 비밀번호 확인에 시도 횟수 제한이 없다.
- 발송을 비동기로 처리하므로 메일 실패를 사용자에게 알릴 수 없다. 배포 전환 중 대기 작업이 사라질 수 있으며 사용자는 다시 요청해야 한다.
- 토큰을 소비한 뒤 DB 저장이 실패하면 링크가 소진되어 다시 요청해야 한다.
- 비밀번호 변경 알림 메일이 없다.
- 비밀번호를 아는 사람은 공용 데모 계정의 비밀번호도 실제로 바꿀 수 있다.
