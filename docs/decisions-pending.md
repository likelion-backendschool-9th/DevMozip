# 미확정 정책과 현재 데모 동작

아래는 **최종 서비스 정책이 아닌 발표용 Mock 규칙**입니다. 기능 구현 여부와 정책 확정 여부는 다릅니다. 모든 권한·제재·사용량은 브라우저에서만 검사합니다.

## 계정·저장

- 인증/세션의 실제 서버 정책은 미확정입니다. 카카오 로그인 정책은 [카카오 인증 API](kakao-auth-api.md), 비밀번호 재설정·변경은 [비밀번호 재설정·변경 API](password-reset-api.md)를 따릅니다. 회원가입은 서버에서 영문·숫자 비밀번호 8~64자 및 닉네임/이메일 중복을 검증합니다.
- 로그인 상태는 백엔드가 발급한 HttpOnly 쿠키로 유지합니다. 로그아웃해도 작성 콘텐츠·월 사용량·구독 데모 상태는 유지합니다.
- 저장 권한/용량 오류에서는 메모리 상태만 유지하며 새로고침 후 보존을 보장하지 않습니다. 손상 데이터는 해당 저장소 초기값으로 복원합니다.
- 다른 브라우저·컴퓨터 간 동기화·동시 편집·서버 충돌 처리는 없습니다. 실제 저장·업로드 제한은 향후 확정합니다.

## 추천·프리미엄

- 무료 월 15회, 프리미엄/관리자 월 100회. 한국 시각 월별·계정별 성공 실행만 차감하고 부족 정보 질문은 차감하지 않습니다. 최종 확대 한도·가격·요금 기간은 미확정입니다.
- 자연어 별칭·기술/분야/직군/협업 상태의 Mock 규칙으로 순위와 적합도를 계산합니다. 실제 AI 정확도나 매칭 성과 지표가 아닙니다. 프로젝트 동점은 최신 생성일 우선입니다.
- 상세 추천 이유, 공개 프로필의 타인 포트폴리오 상세, AI 피드백 데모, 고급 신뢰 온도 검색은 기존 프리미엄/관리자 기능입니다. 공고 생성과 지원자 제출 포트폴리오 상세는 아래 3차 정책을 적용합니다. 본인 포트폴리오 상세는 무료도 열람/수정합니다.
- 표시 가격 월 ₩9,900은 예시. 데모 전환 내역은 ₩0이며 초기 프리미엄 계정의 과거 결제는 명시된 예시입니다. 실제 청구·결제 정보·환불·정기 청구는 없습니다.
- 해지 즉시 무료로 전환하되 콘텐츠/월 사용량을 유지합니다. 이미 15회를 초과했으면 무료 추가 사용은 제한됩니다. 관리자는 구독 전환 대상에서 제외합니다.
- 고급 검색은 최소 신뢰 온도와 온도순 정렬입니다. 기존 무료 기술/직군/경력/분야/협업 필터는 유지합니다.

## 프로젝트·지원·주최자

- 공고 생성은 프리미엄 회원만 가능합니다. 관리자도 생성 우회 권한이 없습니다. 기존 공고 운영은 해당 주최자만 가능하며 해지 후 운영은 임시 유지합니다. 최종 해지 후 관리 정책은 미확정입니다. 관리자는 타인 주최자 권한을 대신하지 않습니다.
- 모집 마감은 한국 시각 날짜 끝까지. 지원에는 본인 포트폴리오·직군·10~1,500자 멘트·해당 직군 최소 경력이 필요합니다. 중복 지원을 막고 취소 후 기간 내 재지원을 허용합니다.
- 지원 취소 패널티 안내는 마감 3일 전 한국 시각 0시부터. −0.5°C는 예시이며 실제 온도 차감은 없습니다. 최종 수치/예외/이의제기 정책은 미확정입니다.
- 새 공고 정원은 주최자 1명 + 직군별 모집 인원. 승인 전 지원서는 팀원/정원에 포함하지 않습니다. 승인은 대기 상태·잔여 슬롯에 한하며 승인/취소 시 인원·팀원·채팅 접근을 함께 반영합니다.
- 기존 팀원 수보다 정원을 줄이거나 대기/승인 인원이 있는 직군을 제거하지 못합니다. 대기 지원자·승인/기존 팀원이 남아 있으면 공고 삭제를 제한합니다.
- 모집 중 → 모집 완료 → 진행 중 → 종료. 모집 완료에서 재모집 가능하나 마감 경과 시 연장이 먼저 필요합니다. 진행 중에서 재모집은 불가, 종료는 되돌릴 수 없습니다. 조기 종료는 가능하나 대기 지원을 먼저 처리해야 합니다.
- 종료 전 승인 취소는 가능하며 팀원·채팅에서 제외됩니다. 종료 후 취소는 협업 이력 보존을 위해 제한합니다. 실제 서비스의 탈퇴/분쟁/강제 퇴장 정책은 미확정입니다.
- 공고 수정/연장/승인/거절/종료 등은 관련 알림을 생성합니다. 모집 기한 경과 관리자 알림은 프로젝트/마감일당 1회입니다. 앱 실행 시·상태 변경·60초 주기로 확인하며 실제 서버 스케줄러는 없습니다.
- 기본 공고 날짜는 2026년 고정 Mock입니다. 발표 시 마감 후라면 연장/신규 공고가 필요합니다.

## 리뷰·신뢰 온도

- 종료된 동일 프로젝트의 등록 협업자 사이, 자기 자신 제외, 작성자/대상자/프로젝트당 1회. 신규 종료는 실제 종료 처리 시각부터 30일, 기존 종료 Mock은 초기 날짜 기준입니다.
- 1~5 정수 별점 필수, 키워드는 선택사항. 자유 서술 리뷰는 없습니다. 리뷰 검수/수정/이의제기와 최종 작성 기한은 미확정입니다. 2차부터 프로필에서는 조회만 하고 프로젝트 요청 링크에서 작성합니다.
- 온도 = 36.5 + Σ(받은 별점 − 3) × 0.5, 0~100°C 제한, 소수 첫째 자리 표시. 별 색상은 36.5 미만 회색 / 38 미만 시안 / 40 미만 보라 / 이후 골드입니다.
- 버블 비율은 전체 선택 키워드 수 대비 각 키워드 횟수. 키워드 없는 리뷰는 분모에 포함하지 않으며 0건은 0%입니다.
- 관리 키워드는 최대 12개·각 1~30자·중복 불가. 선택지 삭제는 신규 선택만 막으며 과거 리뷰와 버블 집계를 유지합니다.

## SNS·팔로우

- 글/댓글은 작성자 수정/삭제, 관리자는 게시글 숨김/복원·댓글 삭제. 퍼가기는 원본 연결·의견·취소를 제공하며 외부 공유는 URL 복사입니다. 원본 숨김/삭제 시 퍼간 글에 안내합니다.
- 이미지 PNG/JPEG/WebP/GIF 최대 3장·각 512KB 이하 Data URL, 서버 업로드 없음. 조회는 브라우저 세션별 추가하는 Mock 값입니다. 인기·추천 지표의 실제 정책은 미확정입니다.
- 팔로잉 활동/모집 알림 설정은 기본 꺼짐. 설정 후 새 이벤트만 생성하고 언팔로우 시 설정을 제거합니다. 기존 알림은 이력으로 남습니다.
- 본인 행위의 SNS 알림은 생성하지 않습니다. 좋아요/팔로우/퍼가기는 동일 대상 재실행 중복을 억제하고 취소 후 이전 알림을 유지합니다. 댓글은 댓글별 생성합니다.

## 대화·프로젝트 채팅·알림

- 일반 메시지 1~2,000자, 협업 제안 본문 10~2,000자·제목 1~100자. 상대 대화를 열면 읽음 처리하고 자동 답장은 생성하지 않습니다.
- 모집 시작 시 프로젝트 방 생성, 승인 시 초대, 취소 시 퇴장·과거 기록 접근 제한. 종료 기본은 읽기 전용 보관, 주최자 선택 시 방/메시지 삭제. 실제 보존 기한·삭제 복구 정책은 미확정입니다.
- 사용자 신고는 신고자/대상당 한 번 Mock 기록합니다. 통합 신고 큐/사용자 신고 운영 처리 연결은 향후 범위입니다.
- 종료와 리뷰 요청은 별도 알림. 개별 읽음/안 읽음·전체 읽음은 계정별 유지하고 헤더에 반영합니다. 푸시·메일 알림은 없습니다.
- Mock 토글 OFF의 서버 메신저는 위 정책을 서버로 옮겨 [메신저 API](messenger-api.md)를 따릅니다. 프로젝트 방은 모집 시작일 이후 첫 접근 때 만들고, 승인·취소는 다음 접근 때 반영합니다. 종료 후 주최자의 방 삭제는 논리 삭제이며 메시지는 DB에 남습니다. 메신저 사용자 신고는 `reports`에 저장만 하고 신고자/대상당 한 번입니다. 새 메시지·읽음·입력 중 표시는 WebSocket으로 다른 기기와 탭에 바로 반영합니다. 메시지 보존 기한·탈퇴 시 처리·관리자 열람 정책은 여전히 미확정입니다.

## 관리자·신고

- 회원 목록은 로그인 가능한 데모/가입 계정입니다. 경고는 사유와 상단 안내, 정지는 로그인/데모 전환 제한. 제재 사유 필수, 관리자 자기 제재 불가. 실제 제재 기한·통지·이의제기 정책은 미확정입니다.
- 프로젝트 신고는 계정/공고당 1회. 처리/기각 메모를 기록하되 공고 삭제·지원 취소·회원 제재를 자동 실행하지 않습니다.
- SNS 신고 검토 완료와 콘텐츠 숨김/댓글 삭제는 별도 작업입니다. 댓글 삭제는 확인 모달을 사용하고 되돌리기 UI는 없습니다. 데모 초기화로 원본 복원은 가능합니다.
- 운영 이력/구독/제재/신고 처리 상태는 로컬 저장입니다. 실제 감사 로그·개인정보 보호·서버 인가·결제 정합성은 후속 백엔드 설계에서 확정합니다.

## 1차 수정의 개인 공간·온보딩 Mock 정책

- 계정 설정 비밀번호는 현재 값 검증·새 값 형식/일치 검증·확인 모달만 수행합니다. 변경 확인 시각만 저장하고 새 비밀번호 원문/해시는 저장하지 않으며 실제 로그인 비밀번호도 유지합니다. 기존 가입 인증의 데모 해시 구조는 변경하지 않습니다. 비밀번호 없는 카카오 회원은 현재 비밀번호 없이 첫 비밀번호를 서버에 저장합니다.
- 카카오 연동은 서버의 `kakao_id`로 관리합니다. 카카오 토큰은 저장하지 않습니다. 결제 수단은 고정된 가상 카드 예시이며 입력이나 실제 결제 정보 저장은 없습니다.
- 계정 잠금은 비공개 계정이라는 의미입니다. 로그인·본인 활동은 유지하고 다른 사용자/비로그인 방문자에게 프로필 상세·팔로우 목록·SNS 작성 글을 숨깁니다. 검색/추천/퍼간 원본/해당 글 활동 알림에도 반영합니다. 기존 locked 저장값은 isPrivate로 이관합니다. 팔로우 승인 절차는 추가하지 않습니다. 관리자 정지와 별개입니다.
- 신규 가입은 자동 로그인 후 온보딩 미완료 상태, 이전 가입/데모는 완료 상태입니다. 임시 작성은 계정별 저장합니다. 전역 강제 라우팅 대신 미완료 안내에서 이어서 작성할 수 있습니다.
- 1단계 닉네임/한 줄 소개 필수, 사진 선택. 2단계 복수 직군·경력·기술·관심 분야 필수(기타 분야로 대체 가능). 3단계 관심 프로젝트 분야·연락 시간 필수, 협업 여부 선택·GitHub/블로그는 선택이고 유효 URL만 허용합니다. 4단계 완료 시 전체 재검증합니다.
- 프로필 사진은 PNG/JPEG/WebP 256KB 이하 로컬 Data URL. 기타 분야 최대 5개·각 30자·중복 불가. 입력은 가상 데이터만 사용하며 실제 개인정보를 넣지 않도록 안내합니다.
- 기존 singular `job`은 대표 직군으로 유지하고 추가 `jobs`를 보존합니다. 공개 프로필은 복수 직군을 표시하며 개발자 검색은 추가 직군도 비교합니다. 기타 분야는 관심 분야에 포함합니다.
- 새 좋아요는 시각을 기록하고 취소하면 제거합니다. 기존 좋아요에 날짜를 임의 생성하지 않습니다. 숨김/삭제된 원본은 좋아요·북마크 개인 목록에 노출하지 않습니다.

## 2차 프로젝트 종료·리뷰 요청 임시 정책

- 내 프로젝트는 호스트/등록 팀원/검토 대기 지원자가 관련된 공고만 표시합니다. 내 참여 탭은 종료 이력도 포함하고 종료 탭으로 별도 모아 볼 수 있습니다. 거절/취소된 지원은 현재 지원 목록에 포함하지 않습니다.
- 예정 개발 종료일은 한국 시각 23:59:59.999까지 정상입니다. 이후 미종료이면 프로젝트/기존 종료일별 1회 주최자에게 알립니다. 연장·종료·삭제하면 이전 안내를 처리 완료로 남깁니다. 새 종료일이 다시 지나면 별도 안내를 생성합니다.
- 팀원 리뷰 요청은 실제 종료 처리 시각이 기록된 프로젝트에서 생성합니다. 기존 고정 종료 Mock은 조회 이력으로 보존하고 소급 발급하지 않습니다. 본인 외 대상이 없는 단독 프로젝트는 요청하지 않습니다.
- 임시 작성 기간/링크 만료는 종료 시각 + 30×24시간. 3일 재알림은 72시간 단위입니다. 정확한 작성 기간·알림 정책은 미확정입니다. 현재 상수는 `mocks/projectWorkspace.ts`의 `reviewPolicy`입니다.
- 요청은 프로젝트/수신자당 1개이고 종료 당시 팀원을 평가 대상으로 고정합니다. 기존 일부 평가를 보존하고 남은 팀원의 별점을 모두 제출해야 합니다. 키워드 선택사항, 자유 서술 없음. 제출은 한 묶음으로 검증하여 오류 시 일부만 반영하지 않습니다.
- 전원 제출하면 사용 완료로 표시하고 요청/재알림을 처리 완료로 전환합니다. 중복 제출과 다른 계정/프로젝트/변조 토큰/기간 외 접근을 Mock 검증합니다.
- 기간 안에 앱을 열거나 날짜를 건너뛰면 놓친 3일 구간별 안내를 보완합니다. 완료자/만료자는 제외합니다. 같은 구간 이벤트 키로 중복을 막고 재로드/날짜 되돌리기로 기존 알림을 반복 생성하지 않습니다.
- 날짜 비교는 앱 로드·동작·열려 있는 동안 기존 60초 확인과 수동 시뮬레이션으로 실행합니다. 서버/백그라운드 스케줄러는 없습니다. 시뮬레이션 시각은 기존 프로젝트 동작의 공통 기준이 되며 생성된 지원/종료/알림 이력은 시간 복원만으로 되돌리지 않습니다.
- 신뢰 온도는 **36.5 + Σ(받은 별점 − 3) × 0.5**, 0~100°C 제한·소수 첫째 자리. 정확한 계산식/색상 임계값은 미확정이며 기존 데모 규칙을 유지합니다. 모든 리뷰 결과는 평균·버블·온도·별 색상에 연결됩니다.
- 임시 토큰/기한/사용 여부는 localStorage Mock 데이터입니다. 실제 서버 인가·서명/해시·탈퇴/분쟁 시 접근·중복 제약·토큰 폐기·트랜잭션은 후속 백엔드에서 확정해야 합니다. 클라이언트 상태는 실제 보안 경계가 아닙니다.
- 프로필/프로젝트는 별도 저장소이므로 저장 차단 시 세션 상태만 유지합니다. 리뷰 저장이 누락되고 사용 완료 메타데이터만 남으면 다음 동기화에서 남은 평가 기준으로 복원하여 기한 내 재시도를 허용합니다. 실제 원자성은 후속 서버 과제입니다.

## 3차 강퇴 투표·모집 권한의 미확정 정책

- 확정 요청 규칙: 대상자는 투표 불가, 계정당 한 번, 찬성 > 전체 투표 가능 인원 / 2. 임계값은 `floor(N/2)+1`이며 정확히 절반이면 미달입니다. 요청자의 자동 찬성은 없습니다.
- **임시**: 주최자는 다른 팀원과 동일한 1표이며 강퇴 대상도 될 수 있습니다. 기간은 72시간, 기권자는 분모에 남습니다. 전원 투표 후 과반수 미달이면 부결, 기한까지 미달이면 만료입니다. 최종 주최자 권한·투표 기간·기권 처리는 미확정입니다.
- 방당 진행 중 투표는 1개, 시작 시 유권자 목록을 고정합니다. 참여자 변경 또는 프로젝트 종료/삭제 시 진행 중 투표를 취소합니다. 동시 투표·재요청 간격·이의제기·복귀 정책은 미확정입니다.
- **임시**: 강퇴는 채팅 접근만 제한합니다. 프로젝트 승인 상태·팀원/정원·활동·리뷰 자격은 유지합니다. 강퇴된 주최자도 프로젝트 소유권/관리 권한을 유지합니다. 강퇴 이후 프로젝트 참여 상태 변경과 주최자 승계는 미확정입니다.
- 강퇴 결과는 관련 팀원/대상자에게 투표·수신자별 한 번 알립니다. 새로고침이나 멤버 동기화로 자동 재초대하지 않습니다. 수동 복귀 기능은 이번 범위에 없습니다.
- 무료 회원은 조회/검색/지원/취소/북마크/참여를 유지합니다. 새 공고 생성은 프리미엄만 허용하고 무료 작성 버튼에서 구독 안내 모달을 제공합니다. 데모 활성화는 실제 결제가 없습니다.
- 지원자 상세 열람은 해당 공고의 프리미엄 주최자에게만 허용하고 제출된 포트폴리오 ID·작성자·지원서 소속을 확인합니다. 비공개 계정의 공개 프로필 접근 권한을 확대하지 않습니다. 원본 포트폴리오가 삭제되면 상세를 생성하지 않습니다.
- 해지한 기존 주최자의 기존 공고 관리는 **임시 유지**합니다. 신규 생성/지원자 상세는 제한하고 재활성화 시 복원합니다. 기존 공고 관리의 최종 구독 요건은 미확정입니다.
- 기간은 기존 Mock 프로젝트 날짜 시뮬레이션과 공유합니다. 서버 시각·원자적 투표/퇴장·서버 인가는 향후 백엔드 사항이며 현재는 브라우저 Mock 검사입니다.

## 4차 대화형 추천 임시 규칙

- 실제 AI 없이 알려진 별칭·숫자 패턴으로 조건을 누적하며 임의의 자연어 정정/부정 문장을 완전히 이해하지 않습니다. 직접 조건 선택/삭제로 보완합니다.
- 복수 분야는 기술 기반 분야 매핑과 텍스트 직접 일치로 비교합니다. 직군/인원은 점수와 이유에 반영하되 자동 팀 편성은 하지 않습니다. 경력은 프로필 연차와 비교합니다. 기간은 일정 데이터 부재로 협의 필요로 표시합니다. 최종 점수식/모집 수요 가중치/일정 적합성 정책은 미확정입니다.
- 첫 필수 조건 완성 시 결과를 생성합니다. 이후 일반 대화·조건 변경·기록 조회/삭제에는 차감하지 않고 추천 버튼 또는 명시적 추천 요청으로 새 결과를 생성할 때 1회 차감합니다. 같은 조건 재추천도 새 결과이므로 차감합니다.
- 무료 15회/프리미엄 100회, 기존 관리자 100회는 유지합니다. 한국 시각 월별 한도이며 지난 월 이력은 보존합니다. 기록 삭제는 사용량 환불이 아닙니다. 월 경계 화면 갱신은 최대 30초 또는 탭 복귀 시, 실제 실행은 현재 시각으로 검사합니다.
- 비로그인 대화는 별도 공간입니다. 로그인 계정으로 자동 병합하지 않습니다. 데이터 보존 기간·기기 간 동기화·동시 탭 편집/원자적 서버 차감은 향후 사항입니다.

## 5차 반응형·검증 범위

- 800px 이하에서 헤더 내비게이션을 다음 행에 배치하고 개인 Aside/AI 기록을 접이식 메뉴로 표시합니다. 펼침은 화면 로컬 상태로 새로고침 시 작은 화면 기본 접힘입니다. 서비스 권한이나 저장 데이터 정책은 바꾸지 않았습니다.
- 페이지 전체 가로 스크롤을 강제로 숨기지 않습니다. SNS 가로 슬라이드·메시지/추천 대화·비교 표 등 내용 탐색용 내부 스크롤은 허용합니다.
- 프로젝트 기간/리뷰/강퇴/구독 해지 후 관리/추천 점수의 기존 임시 정책은 그대로 미확정입니다. 반응형 변경으로 확정하지 않았습니다.
- 실제 검증은 Chromium의 지정 화면 너비/1000px 높이와 일부 터치 에뮬레이션입니다. 실제 스마트폰 하드웨어, Safari/Firefox, 가상 키보드·브라우저별 폰트 확대·기기 간 동기화는 검증하지 않았습니다.

## Next.js 이전과 렌더링 범위

- Mock 저장소를 사용하는 기능은 JavaScript/클라이언트 마운트 후 표시합니다. 서버 레이아웃·metadata·파일 기반 경로는 적용했지만 모든 업무 본문의 SSR/SEO는 이번 범위가 아닙니다.
- 기존 무료/프리미엄·강퇴 후 참여 상태·구독 해지 후 관리·리뷰 기간/온도·AI 점수 정책은 변경하지 않았습니다.
- 실제 서버 인증/동시성/기기 간 동기화와 API 연결은 후속 Spring Boot 작업입니다. 실제 모바일 기기/Safari/Firefox와 LAN 외부 PC 접속은 이번 이전 검증에 포함하지 않습니다.
