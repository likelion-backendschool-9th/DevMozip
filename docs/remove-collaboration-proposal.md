# 협업 제안 UI 제거

- 메신저에서 협업 제안 모드, 프로젝트명 입력, 제안 전송 버튼을 제거했다. 일반 메시지 작성·읽음·신고 기능은 유지한다.
- 개발자 검색 및 AI 추천 결과의 협업 제안 버튼과 전용 모달을 제거했다. 프로필 이동과 팔로우는 유지한다.
- 이전 localStorage 대화를 잃지 않도록 기존 proposal 형식 파서와 대화 기록은 호환 유지한다. 과거 제안도 제목·본문만 일반 대화 기록으로 표시하며 새 UI에서는 만들 수 없다.
- 주요 변경: ChatWindow, MessagesScreen, DeveloperResults, ChatResults, 메시지/검색 화면 테스트, 발표/AI 추천 브라우저 검증 스크립트, 페이지 설명과 신고 선택지.
- 백엔드와 실제 API 변경 없음.

## 검증

- npm run build: 성공.
- npm run typecheck: 성공.
- npm test: develop 기준 PR 브랜치에서 26개 파일, 363개 테스트 통과(프로필 HTML 편집 변경이 함께 있는 작업 디렉터리에서는 376개 통과). 이전 제안 UI를 요구하던 두 화면 테스트를 변경된 동작에 맞게 수정 후 재실행했다.
- 실제 Chromium: 개발자 검색과 채팅의 제안 UI 없음, 일반 쪽지 전송 및 새로고침 복원 확인. 해당 검증 pageerror 0건.
- AI 추천 브라우저 시나리오 13개 통과: 추천 카드의 제안 제거, 프로필 이동, 대화 기록 및 사용량 포함. 결과는 docs/artifacts/revision-4/report.json.
